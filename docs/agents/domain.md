# Domain Docs

本仓库采用 single-context：根目录的 [CONTEXT.md](../../CONTEXT.md) 是领域词汇表，相关决策保存在 [docs/adr/](../adr/)；无需新增 CONTEXT-MAP.md 或移动既有文档。

## 读取规则

- 探索代码前先读[项目索引](../index.md)，按任务读取相关规格、词汇表和 ADR，不一次加载所有历史材料。
- 讨论领域概念、命名规格/任务或修改行为时，使用词汇表的规范用语，避免其列出的混用词。
- ADR 按任务范围读取，确认是否已被后续决定取代；实现和外部验收状态以[项目现状](../status.md)为准，不能从目标方案或历史记录推定通过。
- 发现方案与有效 ADR 冲突时，明确指出冲突及原因；用户已明确更新的决定按其最新确认记录处理。
- 词汇表和 ADR 按实际决策需要更新。文档缺失时继续可开展的探索，不仅为补齐目录而预先创建空文档。

本配置只描述读取方式和位置，产品事实仍由原词汇表、规格及 ADR 维护。
