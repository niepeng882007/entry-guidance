# 05: 个人笔记与交易风格标签

**What to build:** 使用者能为完整交易或不完整记录填写入场理由、退出理由、执行问题、改进事项和自由笔记，并维护自己确认的交易风格标签。笔记与标签长期保存，手机和电脑访问同一份，交易所事实与用户自述清楚分开。

**Blocked by:** 03 — 复杂交易周期归并。

**Status:** done

- [x] 单笔详情可新建、编辑和保存结构化笔记及自由记录，记录保存时间；空白笔记不会生成模型判断或虚构交易理由。
- [x] 用户可维护并应用风格标签；标签属于用户确认的分类，与订单类型和后续模型推测分别表达。
- [x] 持仓中、已结束及不完整记录均可填写笔记，保留所属账户、来源及交易依据；补充历史或重算归并后不静默丢失或错误迁移笔记。
- [x] 笔记与标签服务端持久保存，重新登录、跨设备访问及重启后可恢复；写入失败明确提示并保留用户尚未成功保存的输入。
- [x] 保存入口校验登录、Origin、长度与格式；自由文字仅作为内容展示，不能执行脚本或成为后端配置。
- [x] 页面明确区分用户自述、交易所事实和待确认推测；为后续分析保留用户选择是否发送笔记的边界。
- [x] 编辑、保存反馈及键盘操作遵循既有前端规则，手机输入时主要操作可触达。
- [x] 从公开入口验证保存、更新、重启保留、归并变化、无权限及非法输入，并通过浏览器验证笔记和标签的编辑、失败保留与来源区分。
