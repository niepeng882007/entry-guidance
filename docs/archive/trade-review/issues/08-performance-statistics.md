# 08: 表现统计与分组图表

**What to build:** 使用者能对当前筛选范围查看有效交易数、胜率、净盈亏、平均盈利与亏损、盈亏因子和持仓时长，并通过累计净盈亏曲线与分组比较识别表现规律。统计说明有效样本与排除原因，形成后续 LLM 分析可引用的确定性证据。

**Blocked by:** 07 — 交易列表与组合筛选。

**Status:** implemented — 自动与模拟验收完成，记录见下文；实体手机与真实账户未验收

- [x] 对筛选范围内全部对应数据完整的已结束交易统计，不以当前列表已加载页或逐笔成交数替代样本范围。
- [x] 净盈亏沿用已实现盈亏扣手续费加资金费净收支的口径；相关关键费用或归属不明时从对应指标排除，展示有效样本、排除数量及原因。
- [x] 赢、亏、持平分别计数；胜率为净盈利交易数除以全部可判定净盈亏的已结束交易数，零样本不展示伪百分比。
- [x] 平均盈利与平均亏损分别按正、负净盈亏样本计算；盈亏因子为正净盈亏总额除以负净盈亏总额绝对值，没有亏损样本时明确不适用。
- [x] 展示持仓时长与按平仓时间排列的累计净盈亏曲线；曲线仅反映选定交易结果，不冒充账户权益或完整资金收益率。
- [x] 按币种、方向、入场类型和风格标签提供分组比较，每组展示样本数及未知类别；少量样本不被描述为稳定优势。
- [x] 指标金额使用既有 BigInt 十进制规则，显示舍入不影响内部赢亏判定；图表坐标与单位清楚，手机和桌面可读。
- [x] 同一筛选范围与数据时点产生一致的统计证据，可供报告引用；取消或迟到响应不覆盖当前范围。
- [x] 使用独立预期验证全盈利、全亏损、持平、零样本、缺失费用、分页范围及多标签分组，另验证 HTTP 与浏览器筛选联动和图表展示。

## 已确认实施口径

- 多标签交易完整计入各确认标签组；组间重叠不可相加，未标注归未知。停用标签沿用历史确认关联。
- 金额与时长独立判断：费用缺失只排除金额指标；已结束、空仓起终点及成交链可靠时，时长仍可计入。展示平均、最短、最长时长及独立排除原因。
- 统计公共函数、受保护 HTTP 列表接口、生产浏览器筛选／取消／图表交互为已确认 TDD 边界。审查起点 main = `c6fe4e5`。
- 同一次列表读取在分页前冻结全部匹配数据；证据包括口径版本、范围、身份、交易原值、标签与排除清单，稳定指纹不含读取时间或页码。报告任务可直接冻结该结构，不新增统计存储表。
