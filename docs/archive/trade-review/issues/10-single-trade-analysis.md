# 10: 单笔 LLM 完整上下文分析

**What to build:** 使用者主动发起单笔复盘，模型依据该笔交易的完备上下文生成观察、证据、改进建议和下次检查项。分析作为后台长任务运行，可离开页面、查看进度或取消；报告、覆盖范围、分段结果与返回用量长期保留，失败时由用户选择继续或重试。

**Blocked by:** 08 — 表现统计与分组图表；09 — 单笔行情与交易事件图。

**Status:** done

- [x] 只在用户主动触发时由后端调用已配置的 DeepSeek、deepseek-v4-pro、high；密钥留在后端，页面访问、同步和新成交不自动调用模型。
- [x] 冻结本次完整证据：成交、订单、费用、原方案、已保存核验、标签、允许发送的笔记、带来源和周期的行情、统计与缺失项；后续数据变化不改写运行中的依据。
- [x] 发送笔记由用户选择；凭据、登录信息和无关账户信息不进入模型输入、报告或使用量日志。
- [x] 上下文超过模型容量时全量分段覆盖后综合，保留各段交易、时间和证据清单；不静默抽样或截断，综合阶段明确依据分段结果。
- [x] 报告结构包含观察、证据、改进建议和下次检查项，结论可关联到实际交易、统计或笔记；交易事实、用户自述与模型推测分开，未支持的证据引用不能伪装成事实。
- [x] 支持持仓中及不完整记录的单笔分析，明确缺项和不可判断范围；预算偏离与违反计划、事后走势与当时信息分别表达。
- [x] 后台任务支持查看进度、离开页面后返回与取消，不设调用次数上限或固定 16k 输出、3 分钟等待限制，输出遵循模型可用容量。
- [x] 网络异常、服务中断、取消、分段失败、格式错误或输出截断保持未完成；已完成分段与旧报告保留，不自动重复收费请求，继续或重试由用户明确选择。
- [x] 同样的数据与笔记可复用已有报告，重新生成需主动触发；返回用量可查看，未收到用量显示未知，取消或失败不被描述为免费。
- [x] 报告和任务状态受登录与账户隔离保护；结构化返回在保存和显示前校验，模型文字作为内容展示，不能执行页面脚本或交易操作。
- [x] 使用模拟模型响应验证完整覆盖、证据引用、上下文冻结、分段、未知用量、格式错误、截断、取消、返回恢复和重启中断；生产构建浏览器验证主动触发及报告展示，测试不读取真实密钥或产生调用费用。
