# 06: 原方案关联与执行偏差

**What to build:** 使用者能在交易详情查看有关联的原开仓方案、已保存的查询时点核验及实际成交，识别有证据的预算、入场和止损偏差。未经本工具规划或无法可靠关联的交易保留实际记录，并说明哪些执行问题无法判断。

**Blocked by:** 03 — 复杂交易周期归并。

**Status:** done

- [x] 在原方案生成和核验时保存其对应事实与查询时点，退出、清除本单及服务重启后仍可供复盘查看，原有本单恢复契约继续有效。
- [x] 基于可验证的账户、合约、方向、时间与订单或成交证据关联交易；存在多个候选或证据不足时明确无法关联，不按相近时间强行配对。
- [x] 保留原固定 USDT 预算、绝对止损、数量、入场方式、杠杆与费用假设；实际成交偏差不改写原方案，也不自动扩大预算或移动止损。
- [x] 展示原计划与实际入场、可确认净亏损和已记录止损设置的对照，标明数量、价格、成本及时间口径。
- [x] 已记录核验只代表其查询时点；未记录期间的止损变化或覆盖保持未知，不能推导为持续受保护或持续无保护。
- [x] 区分实际亏损超预算与用户违反计划；滑点、行情缺口或结果亏损不直接证明违规、追涨或情绪动机。
- [x] 未关联方案的历史交易和缺少净盈亏或核验证据的记录仍可查看，并清楚说明不可判断的项目。
- [x] 关联及证据长期留存，为筛选、走势图和 LLM 上下文提供相同的事实口径；保护凭据及原有只读边界。
- [x] 以公开入口和浏览器验证单层、双层、部分退出、原方案固定、歧义关联、历史核验时效及超预算但不能断言违规的场景，原开仓与核验回归通过。
