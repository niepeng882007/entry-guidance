# 03: 普通活跃委托详情

**What to build:** 使用者在独立账户页查看全账户普通活跃委托，包括部分成交后尚未执行的剩余委托。页面展示价格、数量、状态与时间，详细设置按需展开，可按标的筛选；委托刷新后仍能继续阅读，查询失败和没有挂单分别表达。本任务可独立于持仓详情任务实施并通过模拟浏览器验收。

**Blocked by:** 01 — 独立资产快照页。

**Status:** implemented — 本地模拟验收完成，实体手机与真实账户待验收

- [x] 从全账户普通活跃委托读取到独立账户页展示完整打通；不局限于当前开仓方案或选中的单个合约，不受空仓起点限制。
- [x] 主览显示标的、买卖方向、持仓方向、订单类型、适用的委托价、原数量、已成交量、剩余量和当前状态。
- [x] 展开显示委托标识、创建与更新时间，以及接口可读且适用的均价、只减仓和有效方式等设置；字段缺失与不适用分别表达。
- [x] 剩余数量使用既有定点计算入口，验证原数量和已成交量；不以浮点近似或自动修正掩盖无效数量。长委托标识保持原值，不损失整数精度。
- [x] 普通委托正常前台每 3 秒刷新，支持手动刷新与返回读取；记录出现、部分成交或从活跃列表消失后，成功列表准确更新。
- [x] 委托消失只表示本次活跃列表中没有该记录，不推断为成交、撤销或过期，不伪造已实现盈亏。
- [x] 可按标的筛选并区分筛选结果数量与全账户普通委托数量；记录顺序稳定，刷新保留筛选、仍存在记录的展开状态和焦点。
- [x] 无委托、筛选无结果与查询失败分别表达；失败保留旧值及原时间并标过期，不将失败显示为空列表，也不因普通委托失败覆盖成功资产数据。
- [x] 普通委托浏览区能独立使用；与持仓详情共同集成后可在持仓与活跃委托之间切换，不要求先完成持仓任务才读取普通委托。
- [x] 使用现有黑白样式和原生交互，手机高精度价格、数量与长标识完整可读，键盘焦点与减少动态效果设置得到支持。
- [x] 从公开 HTTP 与生产浏览器入口覆盖多标的、多空方向、部分成交、余量精度、委托移除、字段缺失与失败恢复；不发起下单、撤单或其他账户写请求。
