# 单用户单 Binance 绑定，平台加密托管只读凭据

2026-10-16 第二、三轮确认：首版每个产品用户同时一个活跃 Binance 绑定，同一 Binance UID 的归属独占；服务端验证只读权限与稳定 UID 后建立关系，同 UID 换 Key 保留历史，不同 UID 不转移旧账本。解绑撤销凭据，原用户保留只读归档与 UID 占位；注销在线清理完成后释放占位，新绑定不继承旧数据。

用户通过网站提交只读 Key/Secret，由平台长期加密托管，使用户无需自行部署连接服务；用户自备模型 Key 同样长期加密保存。代价是平台承担凭据隔离、访问控制、撤销与恢复责任：凭据不回显，不进入浏览器持久化、日志或用户业务备份，平台受控灾备可含密文，主密钥独立保管；交易、撤单与账户设置仍由用户在 Binance 执行。

注销立即停止登录、凭据使用和新任务，清理交易、个人记录旧版本及冻结快照等在线副本；平台灾备最长 30 天到期，恢复依据独立记录重放删除/撤销，按原归属实例处理以免误伤同 UID 的后来绑定。改变模型 Key 时，未完成分析须由用户明确继续，不能静默改用新 Key 扣费。

目标细节见[架构](../architecture-nextjs-vercel-neon.md#104-托管凭据边界)，实施顺序见[重构计划](../refactor-implementation-plan.md)；票据 04 已增加本地只读绑定与同 UID 换 Key 的凭据托管实现，验证结果及未完成的生命周期范围以[项目现状](../status.md#binance-只读绑定票据-04)为准。
