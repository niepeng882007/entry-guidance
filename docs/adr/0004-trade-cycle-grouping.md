# 主列表按订单展示，完整交易复盘仍按周期归并

2026-10-14 确认：交易记录主列表改为一行一张订单，与 Binance 下载记录一致，单列订单已实现盈亏；从订单可进入关联的完整交易复盘。表现统计、个人笔记、行情与 AI 分析仍采用从空仓到再次空仓的交易周期，使分批入场与退出对应同一笔净盈亏和笔记，避免以订单条数放大胜率样本。

未归零前的加减仓属于同一周期；单向持仓反手拆为结束旧周期与开始新周期，并保留原成交关联。全仓、逐仓历史都纳入，双向持仓按合约与持仓方向分别归并；缺少可靠空仓起点或成交链时保留不完整记录，不将片段伪装为完整周期。

订单列表用于查看交易所执行事实，周期用于表达一次持仓的整体结果。两种记录保留关联，原有周期身份、笔记和统计口径不改成订单身份；反手成本分配与缺口判定见 [复盘规格](../trade-review-spec.md)。
