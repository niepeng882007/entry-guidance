# 复盘按交易周期归并，并保留订单与成交证据

复盘需要同时回顾表现规律和执行问题，主记录采用从空仓到再次空仓的交易周期，而不是订单或逐笔成交；后两者保留在详情中。这样分批入场与退出可对应一笔交易的盈亏和个人笔记，避免以成交条数放大样本数。

未归零前的加减仓属于同一周期；单向持仓反手拆为结束旧周期与开始新周期，并保留原成交关联。全仓、逐仓历史都纳入，双向持仓按合约与持仓方向分别归并；缺少可靠空仓起点或成交链时保留不完整记录，不将片段伪装为完整周期。

以订单为单位更容易直接展示交易所数据，但无法表达一次持仓的整体结果。周期归并会决定笔记、计划关联和统计样本的身份，因此记录其取舍；反手成本分配与缺口判定见 [复盘规格](../trade-review-spec.md)。
