# 一期生成开仓方案，由用户手动执行

此决策已由 [ADR 0003](0003-readonly-account-verification.md) 取代：保留手动执行，加入只读账户核验。以下保留原决策背景。

为先验证工具能否降低开仓前的计算负担并帮助形成止损习惯，一期生成可照填的开仓与止损参数，由用户在 Binance 操作并人工确认；不接交易账户，也不代为下单。

这保留了用户对交易执行的直接控制，但工具无法核验订单是否存在，不能把方案生成或人工确认标记成“交易所已核验保护”。账户只读核验和自动执行若在未来引入，需要另行定义账户接入与订单状态核验责任。
