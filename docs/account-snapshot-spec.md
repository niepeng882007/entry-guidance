# 独立账户快照页规格

现行范围按 2026-10-14 的页面简化及提示调整维护，2026-10-16 对照代码整理。当前页面已实现，验收状态集中在[项目现状](status.md)；原持仓与委托页面设计见[历史规格](archive/account-snapshot-original-spec.md)，不作为本页待实现需求。

## 范围与入口

受登录保护的 `/account` 用于观察单个 Binance 普通 USDT 单资产账户的资产。已有全仓、逐仓、单向、双向持仓均不阻止资产观察；开仓与止损核验仍遵循原有支持范围。

本页仅请求固定 GET `/api/account/assets`，不接受查询参数；移除持仓、普通委托、条件委托的页面模块、筛选与切换，不再请求相应详情或辅助行情。后端既有只读入口及开仓、核验需要的读取能力保留。

工作台仍显示账户摘要，正常每 3 秒刷新；独立页为每轮查询完成后等待 30 秒。账户观察不修改本单冻结预算、绝对止损或自动恢复核验通过。

## 资产与查询信息

| 位置 | 内容与口径 |
| --- | --- |
| 资产主览 | 账户权益、可用余额、未实现盈亏，使用 USDT 金额 |
| 资金占用与查询信息 | 钱包余额、持仓初始保证金、委托初始保证金、维持保证金、可转出额、成功查询及最近尝试时间 |
| 权益 | USDT 钱包余额 + 未实现盈亏，并校验交易所权益字段一致 |
| 可用余额 | 直接使用交易所返回值，不重复减已占保证金，不用可转出额替代 |
| 未实现盈亏 | 查询时点估值，不等同于已扣手续费及资金费的净收益 |

资金明细每次进入默认展开，可手动收起；自动和手动刷新保留本次页面的展开状态和焦点。金额遵循共享 BigInt 十进制定点口径；必要字段非法时本次读取失败，可选字段未返回显示未知，不填零。

数据必须注明来源并验证查询时点，接收时允许最多 60 秒时间差以涵盖观察缓存和传输；过期、倒退、来源错误或金额不一致不形成有效快照。成功时间和最近尝试时间分别保留。

## 刷新与异常

- 首次进入、主动刷新、返回可见和联网恢复发起查询；正常前台每轮完成后等待 30 秒，手动刷新重置计时，忙时不重叠。
- 自动查询使用 `X-Account-Refresh: automatic`，服务端最多复用 30 秒内成功结果并保留原成功时间。主动查询仅合并在途或 2.9 秒内邻近结果；`/api/account` 摘要继续使用短窗口。
- 隐藏、离线或离开时取消待完成请求并暂停；丢弃迟到响应，会话失效停止查询并提供重新登录入口。
- 持续失败和上游 429/418 使用后端退避与冷却；人工刷新和多个页面都不能绕过。账户页遵循 `retryAt`，额度不足或限流暂停，普通资产失败保留旧值。
- 失败保留旧金额和原成功时间，标记“数据待更新”；首次无数据时显示占位，不以零资产或正常成功代替未知。
- 原始错误放入默认收起的“错误详情”，重新查询时清除旧错误。主信息栏只显示简短原因及必要操作：断网为“网络已断开”，校验失败为“账户数据异常，请重新查询”，限流和冷却提示稍后自动重试。
- 正常成功时不显示信息栏。隐藏、返回、缓存等机制不写入用户主流程；冷却时间仍由内部逻辑遵守，页面不显示具体允许读取时点。
- 手动刷新旁用 SVG 圆环表达刷新进度，不显示秒数；查询中显示“刷新中…”。保留模拟来源、异常和登录失效提示。

读取协调由 [src/account-refresh.ts](../src/account-refresh.ts) 和 [src/server.ts](../src/server.ts) 承担。正式生成、完整行情和止损核验保持独立完整查询，不能使用账户观察缓存或部分成功数据生成可执行建议。

## 访问与交互

沿用会话、Host/Origin、固定白名单 GET、静态资源白名单和生产 CSP。凭据留在后端；页面不持久化账户数值，不因读取失败扩大交易、提现或划转权限。

复用现有 Vue、TypeScript、Vite、Node 与黑白灰界面。手机金额完整可读，320px、390px、1280px 无页面横向溢出；原生展开、按钮、键盘焦点及减少动态效果保持。正常刷新不闪动整页，不增加路由、状态管理或动效依赖。

## 验收要求

| 场景 | 必须满足的结果 |
| --- | --- |
| 入口与请求范围 | 登录后可访问；只请求资产，不渲染持仓/委托模块、不发辅助行情请求 |
| 资产口径 | 精确金额、可选字段缺失、非法数值及来源/时间校验符合上述规则 |
| 展开状态 | 首次默认展开，刷新后保持用户选择，重新进入恢复默认 |
| 定时与主动刷新 | 30 秒从上轮完成计时；摘要仍为 3 秒；忙时不叠加，缓存保留原时点 |
| 失败与限流 | 旧金额和成功时间保留，主栏简短，错误详情可查看；手动刷新不绕过冷却 |
| 生命周期与会话 | 隐藏/离线取消，恢复重查；旧响应无效，401 停止并可重新登录 |
| 手机与键盘 | 规定视口无溢出，金额、焦点、展开与刷新可操作 |
| 开仓回归 | 原草稿、正式卡、复制、恢复与核验边界保持，账户数值变化不改写冻结方案 |

HTTP 测试使用现有 Binance 传输替换，浏览器使用生产构建和模拟数据。入口见 [test/account.test.ts](../test/account.test.ts)、[账户页浏览器测试](../test/browser/account-page.spec.ts)和[刷新协调测试](../test/browser/refresh-coordination.spec.ts)；命令见[开发与验证](development.md)。测试存在、历史通过与真实验收分别记录，不互相代替。

## 范围之外

本页不提供持仓/活跃委托浏览、历史权益曲线、交易复盘、收益率、自动止损覆盖判断、后台无人浏览监控或任何交易写入。交易记录、净盈亏、笔记与模型分析由[交易复盘](trade-review-spec.md)承担；原账户任务 01–05 仅保留为[历史档案](archive/account-snapshot/issues/)。
