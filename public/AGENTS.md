# 前端样式修改

项目范围、模块边界及事实来源见 [公共索引](../docs/index.md)。

修改 `frontend/`、HTML、CSS 或前端渲染时遵循本文件。前端采用 Vue + TypeScript + Vite，保留现有样式与原生表单语义；不默认引入组件库、全局状态库或路由。

## 修改入口

- 主题与重复设计值：修改 `style.css` 顶部 `:root` 的变量。颜色按用途命名；`--space-*` 的数字标识现有间距尺度。仅使用一次的布局尺寸保留在所属组件。
- 组件：在 `style.css` 搜索对应类名。基础规则、变体、状态和 `560px` 手机断点放在同一组件段落；共用部件的变体放回该部件，例如按钮放在 Buttons、金额放在 Amount。
- 页面结构：`frontend/EntryWorkbench.vue`、`frontend/components/` 和 `public/login.html` 显式引用样式类。用 `组件__部件` 表达归属，`组件--变体` 表达差异；变体与基础类同时使用，如 `class="button button--text"`。

## 边界

- 新组件先复用已有按钮、表单、金额、明细与提示样式；确有差异时增加具名变体。页面专属规则留在页面组件段落。
- 样式使用类名，ID 用于 JS 定位、表单标签和 ARIA 关联。全局规则只承担基础排版、焦点和隐藏语义；组件内部最多一层后代关系，避免依赖祖先页面或标签嵌套。
- `hidden`、`data-state`、`data-current` 由 Vue 响应式状态绑定，CSS 消费状态。保留 `[hidden]` 的唯一 `!important`，以免 flex/grid 显示已失效的结果。
- 保留原生 input/select/button/details 的类型、属性和事件。表单用 `v-model`，业务状态放在 `frontend/useWorkbench.ts`；DOM 操作仅用于焦点、滚动、模块导航及下拉增强。卸载组件时清理监听、观察器与待完成请求。
- 修改输入、离开页面、断网与查询失败均须撤销当前卡片/核验状态；保留请求序号与输入版本检查，迟到响应不能覆盖新状态。本地恢复方案必须由服务端确认后重新查询。
- 复用 `public/style.css` 中的样式和变量。Vite 打包工作台资源，登录页保留后端原生表单；生产 Node 服务仅发布构建目录内明确列举的 JS/CSS 文件。资源变更须验证登录保护、CSP 和路径拒绝行为。

## 验证

样式重构需对照修改前的登录页、表单、错误状态、草稿、有效/失效开仓卡及核验明细；覆盖 320px、390px、1280px，检查横向溢出、键盘焦点、隐藏/禁用状态和折叠内容。运行 `pnpm check`；浏览器验证使用模拟数据。手机使用 `pnpm build` 后的 HTTPS 服务，重新构建后重启验证。热更新仅供电脑本机开发。
