# 07: 止损模板保存与复用

**What to build:** 用户把自己认可的单层或双层止损百分比与分配比例保存为本地模板，在当前币种和方向上选用后重新计算开仓方案。模板减少重复输入，不携带固定币价，也不替用户作行情判断。

**Blocked by:** 06 — 双层止损规划与剩余仓位核验。

**Status:** ready-for-agent

- [ ] 用户可保存并识别自己的单双层止损模板，字段仅包含止损百分比、层数及分配比例；固定止损价不得跨币种复用。
- [ ] 选用模板时，以当前币种、方向和入场参考价换算绝对触发价，经过同一业务入口完成价格/数量取整、成本、资金和强平校验，展示实际分配比例。
- [ ] 应用模板不偷偷覆盖本单亏损预算、杠杆或资金上限，也不把历史参数声明为适合当前行情的推荐。
- [ ] 原输入为绝对止损价时，保存模板所用百分比必须明确可见；模板应用后不得沿用原币种的绝对价格。
- [ ] 模板和普通偏好存于当前浏览器，刷新后仍可选择；不引入云同步、多人共享或密钥存储。
- [ ] 浏览器存储中的缺失、损坏或非法模板值不能绕过业务验证；显示具体问题并保留用户手动输入能力，不静默使用不合法参数。
- [ ] 应用模板属于方案变更，先取消原通过状态；形成正式建议或核验时仍须读取最新数据，不沿用旧账户、规则或报价。
- [ ] 手机保存、选择和应用模板操作清晰且易触达，使用已有表单与结果卡，不为模板另建一套计算流程。
- [ ] 通过业务入口和一条浏览器流程检查跨币种/多空应用、单双层取整、本地刷新后复用、无效存储及原预算不被修改；测试外部结果，不绑定内部存储函数实现。
