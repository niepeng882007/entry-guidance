# 02: 单层市价开仓试算

**What to build:** 用户在手机单页选择 USDT 永续币种及方向，输入亏损预算、单层止损与成本假设，即时看到市价开仓数量、名义价值和计划止损亏损。试算贯穿账户/行情读取、业务计算和可见结果；在资金与强平检查完成前，结果始终是不可作为正式建议的草稿。

**Blocked by:** 01 — 登录并查看只读账户状态。

**Status:** ready-for-agent

- [ ] 支持做多与做空；选择有效的 USDT 本位永续币种，读取买卖报价、标记价、价格和数量规则及账户适用费率，并显示数据来源与时间。
- [ ] 核对目标币种从空仓开始以及普通单资产、逐仓、单向持仓的适用条件；发现旧仓位、干扰计划的旧委托或不支持的模式时，明确提示需要用户处理，不自行修改账户。
- [ ] 支持固定 USDT 金额或账户权益百分比预算；比例模式采用当前读取的权益，记录本单换算金额。首次不预填示例本金、预算或统一止损距离。
- [ ] 止损支持价格或相对入场参考价的百分比。预算、价格、费率和滑点输入验证明确；止损方向错误或当前标记价已经满足止损条件时，不能输出看似有效的方案。
- [ ] 市价做多参考卖一、做空参考买一；按不利方向分别预留入场与止损退出滑点，并计入开平仓手续费。资金费可另行预留，未预留时明确标注。
- [ ] 按全部仓位在最终止损退出的计划损失反推数量，不将固定名义仓位的价格损失再次乘以杠杆。费用或关键数据缺失时不得无提示用零替代。
- [ ] 使用实际价格与数量步长及可靠十进制计算。止损取整不缩短用户指定的空间，明确展示实际止损价与距离；数量向下取整后复算预算，不擅自增仓满足最小开仓门槛。
- [ ] 修改输入时即时显示草稿数量、仓位名义价值、止损条件、计划止损亏损和成本假设；低频成本设置折叠并可记忆，单位与错误提示适合手机输入。
- [ ] 结果明确标记为草稿，提示资金与强平检查尚未完成，不出现“可执行”或“已核验”状态；查询失败保留输入并撤销有效结果。
- [ ] 通过方案生成的公开业务入口覆盖多空、金额/比例预算、非零手续费与滑点、资金费预留、取整和无效止损；期望采用独立手算，不复制实现算法。补充一条手机输入到结果的流程检查。
