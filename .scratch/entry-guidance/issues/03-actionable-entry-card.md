# 03: 资金与强平校验后的正式开仓卡

**What to build:** 用户在单层市价试算上选择杠杆、最低强平缓冲和可选本单资金上限，看到资金与强平检查结果。仅当账户数据、成本和规则检查成立时，工具生成可逐项复制的正式开仓卡，供用户在 Binance 手动带止损开仓。

**Blocked by:** 02 — 单层市价开仓试算。

**Status:** implemented locally — 真实账户只读联调待补齐凭据；自定义档位系数语义未确认时阻断

- [x] 读取账户适用的杠杆档位和相关交易规则，结合可用余额而非账户权益判断资金是否充足；不得以通用档位假装账户实际限制。
- [x] 用户选择杠杆并可保存常用值；本单资金上限可选。资金需求包括初始保证金、适用开仓浮亏及开仓手续费预留，采用当前官方订单类型/方向估值规则，不将名义价值除以杠杆当作全部成本。
- [x] 最终数量同时满足预算、可用余额、本单资金上限、所选杠杆允许的名义价值及适用订单规则。必要时缩量，保留原止损和所选杠杆；无法满足最小开仓条件时明确拒绝。
- [x] 最低强平缓冲为首次必填的正数个人偏好，可保存，以入场价百分比表达，不预设通用安全阈值。
- [x] 成交前依据官方逐仓公式、账户档位和明确保证金/成交假设计算预估强平价，跨档时复算；不以杠杆倒数代替完整检查。
- [x] 强平缓冲使用有方向的间距：多头最终止损应高于强平价，空头相反。先强平、后止损、缓冲不足或数据缺失时均不得通过，不用绝对值或拉近止损掩盖问题。
- [x] 正式生成前刷新账户、行情和规则，固定本单 USDT 预算及绝对止损参数；后续权益变化不自动改变本单预算。
- [x] 开仓卡突出开仓数量、绝对止损触发价和整仓退出方式，支持逐项复制并明确数量单位；展示名义价值、资金需求、计划损失、预估强平价、缓冲、假设和数据时间。
- [x] 执行说明要求用户采用逐仓、单向持仓、所选杠杆及止损市价、标记价触发、关闭价格保护。工具不下单或调整设置，不把建议生成等同于已经挂好止损。
- [x] 正式建议不承诺实际亏损封顶或交易所一定接受订单。关键数据查询失败时保留旧方案并注明时间，暂停新建议。
- [x] 通过业务入口验证资金不足缩量、开仓浮亏、档位边界、多空缓冲、缺少阈值、数据失败及复制参数一致性；相同仓位改变杠杆不得改变价格风险。完成手机开仓卡的可见流程检查。
