# 01: 登录并查看只读账户状态

**What to build:** 用户能在本地运行的手机网页登录，查看单个 Binance 账户的 USDT 权益、可用余额、连接状态和查询时间。真实账户读取只在后端进行；没有凭据或读取失败时，界面明确显示未连接或失败。遵循只读接入的既有 ADR，为后续开仓规划提供可验证的账户起点。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 提供最小可运行的本地前后端和个人登录流程；登录后能从受保护的账户读取入口看到结果。手机窄屏与桌面均可使用，不引入多用户注册或公网部署。
- [ ] USDT 账户权益与可用余额分别显示，权益采用钱包余额与未实现盈亏的口径；标注查询时间，不把权益当作可投入资金，也不重复扣除已占款。
- [ ] 凭据通过后端环境变量或现有密钥机制配置，不要求用户将密钥发到聊天或填写到手机表单。浏览器、源码、日志和错误信息不泄露凭据或完整签名请求。
- [ ] 使用专用只读凭据并验证所需读取权限；不授予或调用交易、撤单、提现、划转权限，不因读取失败扩大权限。
- [ ] 未登录时页面和账户数据接口均不可访问；后端只允许任务所需的读取请求，不能成为任意地址或任意交易请求的代签代理。
- [ ] 缺少凭据、权限不足、超时或账户口径不支持时，显示明确原因；不静默改用模拟账户或将旧结果标成实时。
- [ ] 无真实凭据时可用明确标识的受控模拟响应验证界面与流程；真实模式不得自动切换为模拟结果，也不在此任务中生成真实开仓建议。
- [ ] 从公开业务/访问入口验证登录成功、未授权访问、余额口径、读取失败、只读请求限制及凭据不泄漏，另检查手机基本布局；测试不依赖真实资金操作。
- [ ] 提供本地启动、验证和配置方式，敏感值仅使用占位说明。技术栈选择保持最小，不为后续功能预建无使用者的抽象。
