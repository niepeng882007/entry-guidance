# 22: 带归属证明的备份与事务恢复

**What to build:** 用户能导出完整 v2 业务备份，预览补缺与冲突后恢复到同一有效归属，失败不会破坏原账本。

**Blocked by:** 13 按日期下载订单并补齐历史；16 原方案与实际执行对照；21 筛选范围批量 AI 分析。

**Status:** ready-for-agent

**规格关联：**用户故事 68、69、70、71；实现决策 7、10、12、18、19。

- [ ] 覆盖全部十二类业务记录及原始证据，新封装包含不可复用归属及服务端证明，不含明文、密文 Key 或凭据引用。
- [ ] 恢复核对当前用户、来源、UID、归属实例及有效状态，文件字段本身不是授权；普通备份方案不成为可信当前本单。
- [ ] 保留新增/重复/冲突/拒绝预览，只有选中的个人记录可覆盖，并保存双方旧版本。
- [ ] 预览后账本变化拒绝旧确认；恢复与任务写入互斥，事务失败完整回滚，导入任务不自动执行。
- [ ] 保留 64 MiB 恢复上限与受限文件授权，覆盖过期、重放、越权、大文件和并发失败。
- [ ] 旧 v1 不进入公开跨用户恢复路径，留给受控迁移转换；恢复页面和数据库行为均验收。
