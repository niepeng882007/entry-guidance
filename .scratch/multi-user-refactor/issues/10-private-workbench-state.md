# 10: 私有偏好、模板与手机返回恢复

**What to build:** 用户可保存自己的偏好和止损模板，并在手机切换 App 或页面返回后恢复本单，不暴露给其他登录者。

**Blocked by:** 07 单层成交核验与可信本单恢复。

**Status:** ready-for-agent

**规格关联：**用户故事 30、31、33、34、79；实现决策 20、21。

- [ ] 偏好、模板、输入和本单按产品用户及必要账户作用域隔离，身份确认前不加载旧私有状态。
- [ ] 保留原有模板应用、复制、未保存提示、键盘和返回交互；当前方案恢复仍走可信服务端确认。
- [ ] 跨标签退出、用户切换及绑定代次变化清除可见旧状态，迟到请求不能重新显示它。
- [ ] 历史无归属本地数据不自动分配给下一位用户，预留受控原拥有者迁移路径。
- [ ] 覆盖 Chromium/WebKit、三个既定视口和模拟 App 返回，实体设备验收另记。
