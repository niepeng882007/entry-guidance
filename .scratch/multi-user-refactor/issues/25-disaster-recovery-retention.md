# 25: 隔离灾备恢复与 30 天清理

**What to build:** 维护者能在隔离环境恢复账本并重放删除和撤销决定，证明旧用户、旧凭据和旧任务不会随快照复活。

**Blocked by:** 24 注销、完整清理与独立撤销记录。

**Status:** ready-for-agent

**规格关联：**用户故事 77、78、81；实现决策 7、10、11、24。

- [ ] 恢复默认关闭用户访问及 Binance/模型调用，从独立控制记录重放到可信最新位置后才开放。
- [ ] 缺少、损坏或不完整控制记录时保持关闭；恢复代次使旧会话、委托凭据和任务执行权失效。
- [ ] 按原归属实例重放，已注销后同 UID 的新绑定不被误删，授权不明的恢复凭据要求用户重新提交。
- [ ] 验证密文备份与独立主密钥的恢复/轮换边界，业务备份仍无凭据。
- [ ] 以可控时钟验证所有平台旧库、演练库、迁移导出及临时副本最长 30 天清理；控制记录覆盖全部尚可恢复副本。
- [ ] 通过操作入口/恢复工具和恢复后 HTTP 行为给出完整演练报告，不把本地模拟当云平台实际保留配置已验收。
