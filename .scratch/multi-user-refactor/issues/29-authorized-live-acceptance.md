# 29: 真实只读链路与实体手机验收

**What to build:** 在明确授权的测试范围内，维护者核实真实服务与实体手机的可用性，并分别记录通过和未通过的能力。

**Blocked by:** 28 选定资源并部署隔离试运行环境。

**Status:** ready-for-agent

**规格关联：**用户故事 10、34、38、55、77、82；实现决策 1、7、14、17、22、25。

- [ ] 只在授权账户和范围内核实 Binance 只读权限、UID、网络出口、限流及必要同步字段；不得扩大写权限或代为交易。
- [ ] 使用授权的用户模型 Key 验证实际元数据、分段报告和用量，不自动重复收费尝试，明确费用未知情况。
- [ ] 验证真实 Neon 连接、事务、恢复隔离和删除重放；不把本地 PostgreSQL 通过当云兼容证明。
- [ ] 记录实体手机 HTTPS、软键盘、焦点、复制及切换 App 返回；Binance App 双层组合等外部验收按真实证据记录，不由模拟替代。
- [ ] 自动、模拟浏览器、实体手机、Binance、模型及恢复证据分别归档；未通过的关键能力阻止最终切换，不编造完成状态。
