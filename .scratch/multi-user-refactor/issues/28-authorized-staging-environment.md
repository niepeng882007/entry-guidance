# 28: 选定资源并部署隔离试运行环境

**What to build:** 在地区、预算及资源获得明确确认后，维护者能部署完整且隔离的试运行环境，并看到实际资源与恢复能力。

**Blocked by:** 27 移除旧栈并完成全量本地验收。

**Status:** ready-for-agent

**规格关联：**用户故事 82；实现决策 2、7、10、11、22、25。

- [ ] 执行采购前明确用户地区、月预算、主机/数据库区域、域名、发信身份、主密钥保管和独立控制记录设施；未授权不采购。

- [ ] 验证小请求、数据直连、传输大小与代理超时、CSP、精确来源和服务间身份；Next 无 Key 解密能力。
- [ ] 按实际供应商验证最长 30 天保留/清理、独立恢复控制记录和备份主密钥分离，不仅检查配置文字。
- [ ] 提供可复现发布/回滚说明及实际费用估算，不默认新加坡、固定预算或云兼容已通过；本票不迁移真实账本。
