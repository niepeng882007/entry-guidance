# 03: 密码恢复与设备会话管理

**What to build:** 用户可找回和重置密码、撤销其他设备会话；旧网页和业务直连随会话撤销失去访问权。

**Blocked by:** 02 公开官网与邮箱注册验证。

**Status:** ready-for-agent

**实施状态：**已完成（2026-10-16，本地合成验收）。

**规格关联：**用户故事 6、7、9；实现决策 1、3、4、22。

- [x] 通过页面完成找回、重置及会话管理，验证链接过期、重复消费和错误来源被拒绝。
- [x] 重置和撤销策略在服务端落实，业务服务每次检查当前会话状态，旧委托凭据不能继续访问。
- [x] 区分数据库不可用与未登录，不因依赖故障误清有效会话或放开鉴权。
- [x] 跨标签退出、浏览器返回及两用户切换不出现原用户私有内容；普通登出不被定义为取消后台任务。
