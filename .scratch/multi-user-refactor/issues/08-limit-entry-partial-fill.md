# 08: 限价开仓与部分成交处理

**What to build:** 用户可生成 GTC 限价开仓方案，部分成交后按实际仓位核验，并明确处理尚未取消的入场余单。

**Blocked by:** 07 单层成交核验与可信本单恢复。

**Status:** ready-for-agent

**规格关联：**用户故事 25、29、30；实现决策 13、15、20。

- [ ] 限价专属输入、资金与数量计算、生成和恢复贯通，其他输入保持现有语义。
- [ ] 部分成交保留原计划，只按实际仓位和已发生费用核验，不把未成交数量当成持仓。
- [ ] 有入场余单时提示用户在 Binance 处理，工具不代撤单或把未处理状态判通过。
- [ ] 限价变更、迟到响应、恢复及异常路径均能使旧卡片失效。
- [ ] 原限价和部分成交计算、HTTP 与手机浏览器场景通过，并维持单层市价回归。
