# 15: 复盘笔记、标签与未保存草稿

**What to build:** 用户可为完整交易保存笔记和风格标签，页内导航保留草稿，并在并发修改时得到明确冲突提示。

**Blocked by:** 11 完整交易账本与分页详情浏览。

**Status:** ready-for-agent

**规格关联：**用户故事 49、50、79；实现决策 12、20、21。

- [ ] 笔记、标签、交易依据和版本从 PostgreSQL 到页面完整往返，用户自述不混作交易所事实。
- [ ] 并发更新使用版本/依据条件，不能静默覆盖新内容；归属不明的记录继续可查看原依据。
- [ ] 页内列表与详情切换保留草稿，整页离开有未保存提示。
- [ ] 账号、绑定或会话变化隐藏原草稿，跨标签退出及迟到保存不得泄露或写错用户。
- [ ] 通过公开接口检验并发、版本冲突及失败保留，通过浏览器验证草稿与手机输入。
