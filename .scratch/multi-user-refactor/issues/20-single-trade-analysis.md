# 20: 单笔 AI 全量分析与任务续跑

**What to build:** 用户主动发起单笔分析后，可查看全量分段报告、取消任务或在中断后继续，离开页面不丢失已接受任务。

**Blocked by:** 12 手动历史同步与周期归并；15 复盘笔记、标签与未保存草稿；18 双来源行情与交易事件图表；19 自备模型 Key 设置与撤销。

**Status:** ready-for-agent

**规格关联：**用户故事 53、57、58、59、60、62、63、64、65、66、67；实现决策 10、16、17、18。

- [ ] 冻结交易、统计基础、全部已归档行情和用户允许的笔记，敏感凭据及内部身份不作为模型内容。
- [ ] 复用持久任务执行权和检查点，公平排队；超容量全量分段后综合，不截断或遗漏证据。
- [ ] 任务提交/进度返回摘要，历史分页及报告/证据按需完整取得，较大 JSON 走受保护数据通道。
- [ ] 普通登出与离开不取消已接受任务；主动取消、权限失效和密钥撤销阻止后续调用并保留已发生尝试信息。
- [ ] 失败及结果未知请求不自动重放；换 Key 后需用户明确继续才能使用新版本，未知用量不能解释为免费。
- [ ] 页面和 HTTP 覆盖注释许可、取消、重启、双实例争抢、证据校验和大报告，模型输出只作为文本展示。
