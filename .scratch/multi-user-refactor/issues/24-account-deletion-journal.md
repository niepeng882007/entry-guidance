# 24: 注销、完整清理与独立撤销记录

**What to build:** 用户重新认证并选择注销后立即失去访问权，平台完成全部在线清理后释放 UID，后来绑定者不能继承原资料。

**Blocked by:** 03 密码恢复与设备会话管理；23 解绑、只读归档与换账户。

**Status:** ready-for-agent

**规格关联：**用户故事 7、76、77、78；实现决策 9、10、11。

- [ ] 注销先提供导出机会，确认后立即停用会话、凭据和新业务任务，并展示明确的清理状态。
- [ ] 删除/撤销决定在确认成功前进入不随业务库恢复点回退的持久控制记录；记录不包含交易、笔记或 Key。
- [ ] 清理涵盖十二类数据、笔记旧版本、冻结分析快照、临时文件和私有缓存，并阻止任务迟到写回。
- [ ] 在线清理完整完成后才释放 UID；新绑定使用不可复用的新归属，旧备份不能复活原资料。
- [ ] 按用户、归属实例和版本撤销，不能误伤同 UID 的后续合法绑定。
- [ ] 通过公开操作及隔离持久存储验证中断重试、并发任务、会话失效和全部副本清理，不读真实数据。
