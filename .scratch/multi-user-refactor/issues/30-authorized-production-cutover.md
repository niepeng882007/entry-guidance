# 30: 授权后的停写切换与试运行交付

**What to build:** 在真实迁移和生产部署获得独立确认后，原用户的数据经对账切换到新产品，并具备正确的回退与运行记录。

**Blocked by:** 29 真实只读链路与实体手机验收。

**Status:** ready-for-agent

**规格关联：**用户故事 80、82；实现决策 11、23、24、25。

- [ ] 确认真实迁移范围与窗口，停止旧任务和写入，保全原库及凭据撤销状态，不长期双写。
- [ ] 明确原拥有者，迁移并核对全部账本及当前本单；缺乏可信归属或未解决本单阻止对应账户切换。
- [ ] 新系统开放写入前失败可撤销切换；产生需保留的新写入后只能回退兼容 Neon 的应用或维护，旧 SQLite 不恢复可写。
- [ ] 发布网页与业务服务兼容版本，进行受保护冒烟、数据隔离与任务检查；不公开未验收能力。
- [ ] 交付试运行资源、费用、验收、恢复和副本清理记录；平台旧库只读留存并按最长 30 天清理，用户本机原件由用户控制。
