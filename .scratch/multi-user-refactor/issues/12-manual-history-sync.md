# 12: 手动历史同步与周期归并

**What to build:** 用户可主动同步历史并形成可追溯的完整交易；分页或服务中断后保留检查点，只在用户继续时恢复。

**Blocked by:** 05 资产快照与多用户读取协调；11 完整交易账本与分页详情浏览。

**Status:** ready-for-agent

**规格关联：**用户故事 40、41、44、45、47；实现决策 12、14、15、16。

- [ ] 首次默认范围和后续主动更新沿用现行规格，覆盖历史合约、费用、反手及双向周期归并。
- [ ] 持久保存原始记录、覆盖范围、缺口和分页检查点，未知范围不得宣称完整。
- [ ] 同账户归档串行，任务原子领取、租约和执行版本在重启/交接时防止重复执行或迟到写入。
- [ ] 页面进入、聚焦、联网恢复和任务完成不自动发起 Binance 查询或擅自刷新列表。
- [ ] 同步进度、主动继续和原始证据可在页面验证；模拟分页失败、限流、关闭页面及双实例争抢。
