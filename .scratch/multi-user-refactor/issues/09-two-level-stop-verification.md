# 09: 双层止损与近端退出后余仓核验

**What to build:** 用户可生成双层止损方案，并在近端退出后检查剩余仓位、已发生成本及最终止损覆盖。

**Blocked by:** 07 单层成交核验与可信本单恢复。

**Status:** ready-for-agent

**规格关联：**用户故事 22、29；实现决策 12、13、20。

- [ ] 初始数量仍按全部仓位在最终止损退出计算，不使用加权止损距离放大仓位。
- [ ] 分层数量按步长和风险方向取整，整仓最终止损与部分止损重叠不重复计算覆盖。
- [ ] 近端执行、取消或部分退出后保留原预算和止损，按余仓及实际成本重新核验。
- [ ] 界面区分近端部分退出与最终退出方式，缺失证据不能给出通过状态。
- [ ] 双层纯计算、HTTP 及手机页面回归通过；真实 Binance App 组合操作仍留在外部验收任务。
