# 07: 单层成交核验与可信本单恢复

**What to build:** 用户手动成交后可核验实际成本与止损覆盖，并在刷新、重登或服务重启后恢复原方案继续查询。

**Blocked by:** 06 单层市价开仓草稿与固定方案。

**Status:** ready-for-agent

**规格关联：**用户故事 27、29、30、31；实现决策 12、13、21。

- [ ] 按查询时点检查实际持仓、成本、入场余单和止损覆盖，空仓或数据不全不能判通过。
- [ ] 恢复固定原预算、绝对止损及原账户归属，跨用户或错误 UID 的恢复被拒绝。
- [ ] 输入变化、离开、断网及查询失败撤销当前通过状态，恢复后必须重新查询。
- [ ] 可信当前方案与普通历史备份分开，不能通过客户端编辑参数扩大已有持仓的预算。
- [ ] 记录原方案和核验证据，覆盖服务重启、会话切换、存储失败及两用户恢复隔离。
