# 13: 按日期下载订单并补齐历史

**What to build:** 用户可按北京时间范围手动获取历史订单文件，复用已有下载任务，并明确看到补齐范围、额度或格式异常。

**Blocked by:** 12 手动历史同步与周期归并。

**Status:** ready-for-agent

**规格关联：**用户故事 45、46、47；实现决策 12、14、15、16。

- [ ] 日期输入、任务创建/复用、固定主机下载、文件解析及落账形成完整闭环。
- [ ] 结果未知且无任务 ID 时不自动再次申请；已知 ID 继续复用，已覆盖区间不重复下载。
- [ ] 文件 UID、时间、ZIP/CSV 和大小校验失败不污染原账本，也不伪造完整净盈亏。
- [ ] 下载不可用或额度不足时保留任务与缺口，普通历史接口仅补其可取得范围。
- [ ] 用户可在归档界面查看状态和原始证据；以合成文件、异常响应和重启检查点验收。
