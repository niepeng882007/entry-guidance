# 18: 双来源行情与交易事件图表

**What to build:** 用户可查看已归档合约价和标记价行情，主动补查并叠加交易事件与止损证据。

**Blocked by:** 05 资产快照与多用户读取协调；11 完整交易账本与分页详情浏览。

**Status:** ready-for-agent

**规格关联：**用户故事 52、53；实现决策 12、14、15、18、20。

- [ ] 默认仅读取已有行情，切周期或恢复网络不自动访问 Binance；主动补查才分页读取并落账。
- [ ] 两种来源各自保留覆盖、查询时点和缺口；实际成交与止损触发依据分别表达。

- [ ] 交易与行情按用户、账户和周期隔离。
- [ ] 合成分页、缺口、取消、周期切换和手机图表交互通过，模型后续可读取全部已归档行情。
