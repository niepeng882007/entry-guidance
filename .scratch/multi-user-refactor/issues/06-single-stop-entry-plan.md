# 06: 单层市价开仓草稿与固定方案

**What to build:** 活跃账户用户可填写单层市价计划、即时看草稿，并在严格读取后生成固定预算和绝对止损的正式开仓卡。

**Blocked by:** 05 资产快照与多用户读取协调。

**Status:** ready-for-agent

**规格关联：**用户故事 19、20、21、23、24、26、27、28；实现决策 12、13、15、20。

- [ ] 复用现有 BigInt 十进制计算、交易步长、费用与强平缓冲规则，不把金额中转成浮点。
- [ ] 正式生成刷新必要账户、行情和合约规则，严格读取不复用过期观察缓存。
- [ ] 资金不足仅缩量，不放宽风险；缺失、不一致或已触发止损的输入不能生成有效新方案。
- [ ] 方案、输入、来源和稳定账户归属可靠保存，存储失败明确失败，不出现未保存却可执行的卡片。
- [ ] 移动表单、卡片、复制和错误状态可演示；纯计算边界与 HTTP/浏览器验证通过，所有交易仍手动执行。
