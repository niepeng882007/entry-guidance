# 14: 订单主列表与完整交易关联

**What to build:** 用户默认看到一行一张订单的记录表，并可从订单进入相关完整交易，保留现有筛选与手机浏览体验。

**Blocked by:** 13 按日期下载订单并补齐历史。

**Status:** ready-for-agent

**规格关联：**用户故事 39、41、42、43、44、48；实现决策 12、20、21。

- [ ] 展示订单时间、类型、买卖方向、均价、数量、状态和订单已实现盈亏，保留取消、过期及部分成交记录。
- [ ] 盈亏从实际成交汇总，成交未补齐时待确认，手续费与资金费不混作订单净盈亏。
- [ ] 反手可关联两个完整交易，订单成交不重复计数，周期笔记和统计身份不改成订单身份。
- [ ] 北京时间日期、交易对、分页、URL 及展开明细保持现有规则；表格可横向滚动但页面不溢出。
- [ ] 已绑定用户及归属隔离、缺项与大列表的 HTTP/浏览器验收通过。
