# 11: 完整交易账本与分页详情浏览

**What to build:** 用户能从 PostgreSQL 账本浏览自己的完整交易、筛选分页并打开包含证据与缺口的详情。

**Blocked by:** 04 Binance 只读绑定与同账户换 Key。

**Status:** ready-for-agent

**规格关联：**用户故事 40、41、42、43、44、47、48；实现决策 5、12、20、21。

- [ ] 在保留旧同步账本调用的同时扩展可等待的新账本边界，首批迁移交易与证据读取，避免一次改坏所有调用方。
- [ ] 以合成完整和不完整周期贯通数据库、HTTP 与 React 列表/详情；不得用共享演示数据替代用户归属。
- [ ] 保留稳定周期身份、北京时间日界线、每页 20 条、筛选和详情返回状态。
- [ ] 缺少成交链、成本或开仓起点时保留已知事实及缺口，不补造完整性或零盈亏。
- [ ] 两用户相同记录编号、详情越权、分页边界和错误查询均有对外行为测试；旧回归链保持可运行。
