# 21: 筛选范围批量 AI 分析

**What to build:** 用户可对当前筛选的最多 100 笔完整交易发起批量分析，获得覆盖全部选中记录且明确排除依据的报告。

**Blocked by:** 17 全范围统计与 CSV 导出；20 单笔 AI 全量分析与任务续跑。

**Status:** ready-for-agent

**规格关联：**用户故事 53、59、60、61、62、67；实现决策 16、17、18。

- [ ] 冻结筛选全范围而非当前页，超过 100 笔明确拒绝并要求缩小范围，不静默抽样。
- [ ] 排除样本仍保留逐笔证据，仅按对应指标规则排除统计贡献。
- [ ] 全量分段与综合引用可追溯，任一分段失败整体不标完成。
- [ ] 复用单笔任务的排队、取消、Key 版本、人工继续和未知费用语义。
- [ ] 大报告、覆盖清单及统计明细可完整取得，HTTP 与浏览器验证筛选变化、范围边界和多用户隔离。
