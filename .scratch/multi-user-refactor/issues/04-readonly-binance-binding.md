# 04: Binance 只读绑定与同账户换 Key

**What to build:** 用户在设置页提交只读 Key，验证后获得独占账户绑定，并可更新同 UID 的 Key 而保留身份与历史。

**Blocked by:** 01 兼容启动与隔离登录工作台。

**Status:** ready-for-agent

**实施状态：**已完成（2026-10-16，本地合成验收；已合并并推送 main，不代表真实交易所链路或公共部署通过）。

**规格关联：**用户故事 10、11、12、13、14、16、17、18；实现决策 5、6、7。

- [x] 由后端核实全部要求的只读权限并读取稳定 UID；含写权限、身份不明或失败时不建立有效绑定，也不删除原数据。
- [x] 数据库保证每用户最多一个活跃绑定及 UID 独占，并发冲突只有一个成功；不泄露其他所有者身份。
- [x] Key 认证加密并绑定所属用户、用途与版本，主密钥独立提供；错用户、篡改或错误版本不能解密使用。
- [x] 同 UID 换 Key 更新授权代次并保留归属，不同 UID 不能靠修改字段改挂旧历史。
- [x] 凭据不回显、不写浏览器持久存储或日志；未绑定用户可进入设置，模拟和真实身份分开。
- [x] 设置页面、HTTP 和真实本地 PostgreSQL 并发用例通过；首版公共部署仍需最终整合门禁。
