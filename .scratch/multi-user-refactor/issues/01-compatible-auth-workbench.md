# 01: 兼容启动与隔离登录工作台

**What to build:** 使用两个预置的合成用户分别登录新工作台，经受保护的 Next 到 Node 链路读取各自资料；原单用户演示流程继续可运行。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

**规格关联：**用户故事 6、8、9、79、81；实现决策 2、3、4、20、21、22、25。

- [ ] 记录原版本完整检查基线，明确既有失败；新增工程检查覆盖两个运行入口，旧流程不因扩展入口而失效。
- [ ] 新工作台、数据库会话和业务服务资料读取形成完整链路；未登录、停用、伪造委托凭据及跨用户读取均被拒绝。
- [ ] 先隔离旧入口与新身份边界；新用户不能透传访问旧单用户数据，旧登录不成为第二套新产品身份源。
- [ ] Next 不持有用户 Key 解密能力；浏览器委托凭据只驻内存和请求头，退出隐藏私有数据并拒绝迟到响应。
- [ ] 提供本地合成用户、隔离数据库及生产构建浏览器验收；为后续迁移保留旧入口，避免一次替换全部调用方。
