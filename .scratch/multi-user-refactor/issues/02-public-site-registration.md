# 02: 公开官网与邮箱注册验证

**What to build:** 访客能阅读公开官网并注册，完成邮箱验证后进入自己的工作台；邮件失败能通过重发继续。

**Blocked by:** 01 兼容启动与隔离登录工作台。

**Status:** ready-for-agent

**规格关联：**用户故事 1、2、3、4、5；实现决策 1、20、22。

- [ ] 官网初始 HTML 含真实产品正文及必要元数据，私有业务和认证页面的索引边界正确，不加载用户私有内容。
- [ ] 完成注册、验证、登录的页面到数据库闭环；未验证用户无法读取私有业务。
- [ ] 邮件发送失败保留待验证账号，可限流重发；不把邮件接收成功当作最终送达。
- [ ] 注册、重发及相关写请求具备来源校验和共享限流，响应不泄露其他用户资料。
- [ ] 本地使用 fake 邮件适配，覆盖两个用户、失败重发、公开 HTML 与生产 CSP；不采购域名或真实发信。
