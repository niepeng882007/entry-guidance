# 19: 自备模型 Key 设置与撤销

**What to build:** 用户可在设置页加密保存、替换或撤销自己的模型 Key；没有有效 Key 时仍可使用非 AI 功能和旧记录。

**Blocked by:** 04 Binance 只读绑定与同账户换 Key。

**Status:** ready-for-agent

**规格关联：**用户故事 17、18、54、55、56；实现决策 7、17。

- [ ] 模型 Key 按产品用户授权，尚未绑定 Binance 的已验证用户也可设置；不能误用账户绑定授权前置条件。
- [ ] 沿用当前支持的模型配置，固定服务端目标，不接受任意用户模型 URL，也没有公共 Key 回退。
- [ ] Key 不回显、不进入持久浏览器状态或用户业务备份，替换/撤销可靠更新版本与失效记录。
- [ ] 页面清楚表达费用由用户向模型商承担，用量不等同账单金额。
- [ ] 通过合成凭据与替换模型 transport 验证保存、失败、版本变化和跨用户访问，不调用真实收费服务。
