# 16: 原方案与实际执行对照

**What to build:** 用户在交易列表与详情中看到可信原方案与实际执行的对照，无法唯一关联时明确保持未确认。

**Blocked by:** 07 单层成交核验与可信本单恢复；11 完整交易账本与分页详情浏览。

**Status:** ready-for-agent

**规格关联：**用户故事 48；实现决策 12、13。

- [ ] 复用长期保存的方案与查询证据，仅在唯一可信关联时展示原预算、入场、净亏损及止损设置对照。
- [ ] 列表、详情和后续分析使用相同关联口径，不从亏损结果推断违规或补造历史意图。
- [ ] 缺 UID 的旧凭证、普通备份方案、冲突关联及缺失历史止损证据不被升级成可信当前方案。
- [ ] 跨用户同订单或方案编号不能建立关联。
- [ ] 用真实本地账本和模拟证据覆盖唯一、歧义、缺失及边界成本，并完成页面验收。
