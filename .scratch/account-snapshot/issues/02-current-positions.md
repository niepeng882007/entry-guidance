# 02: 全部当前持仓与行情详情

**What to build:** 使用者在独立账户页查看当前账户全部 USDT 本位永续持仓，包括全仓、逐仓、单向和双向持仓，以及未经本工具生成方案的仓位。每份持仓显示标记价和未实现盈亏 USDT 金额，详细参数按需展开，可按标的筛选；持仓与辅助行情正常前台每 3 秒更新，读取失败有明确状态。

**Blocked by:** 01 — 独立资产快照页。

**Status:** implemented — 自动与模拟浏览器验收通过；实体手机、真实账户未验收

- [x] 从全账户只读持仓入口到页面展示完整打通，已有仓位可以查看；不复用要求目标合约空仓、逐仓和单向的开仓前检查。
- [x] 覆盖全仓、逐仓、单向和双向持仓；同一合约的多头与空头分别显示，不将多空净额当作单份持仓，也不遗漏未经工具生成方案的仓位。
- [x] 主览显示标的、多空、保证金模式、杠杆、持仓数量、入场均价、标记价与交易所返回的未实现盈亏 USDT 金额。
- [x] 展开显示最新成交价、仓位名义价值、当前强平价、保本价、逐仓资金、可读取到的资金费率和下次结算时间，以及对应数据时间。
- [x] 标记价、最新成交价与入场均价明确命名；未实现盈亏不称为扣除手续费或资金费后的净收益，不增加收益率百分比，不以新价格自行重算并冒充交易所盈亏。
- [x] 支持标的筛选，明确筛选结果数量与全账户持仓数量；默认按标的和持仓方向保持稳定顺序，刷新保留仍存在记录的展开状态与焦点。
- [x] 成功读取空仓、筛选无结果与持仓读取失败分别显示；读取失败保留旧持仓及原时间并标过期，不将失败显示为空仓。
- [x] 辅助行情失败时持仓事实仍可显示，辅助价格或资金费数据标明未知或过期及原时间；不得把不同查询时点伪装为同时取得。
- [x] 新持仓出现、数量变化或持仓消失时按成功读取的新列表更新，不擅自归因或补造历史成交。数量及金额保持既有定点精度。
- [x] 账户观察范围扩展不改变正式开仓和原止损核验的支持模式，也不改写已生成方案的冻结预算与绝对止损。
- [x] 盈亏颜色与符号含义明确，数字对齐，详细参数在手机可完整阅读；轻微更新与展开动效尊重减少动态效果偏好，不每次刷新闪动整个列表。
- [x] 使用公开 HTTP 与生产页面覆盖多标的、同标的双向、正负盈亏、可选字段缺失、辅助行情失败、空仓及持仓变化；只替换 Binance 外部响应，不读取真实账户。
