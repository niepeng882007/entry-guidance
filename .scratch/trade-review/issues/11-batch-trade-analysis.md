# 11: 筛选范围批量 LLM 分析

**What to build:** 使用者主动对当前筛选范围最多 100 笔交易发起批量复盘，结合全部有效统计及逐笔证据回顾表现规律和执行问题。数据过大时完整分段再综合，每条结论能追溯到交易或统计分组，报告不会把部分覆盖冒充全范围完成。

**Blocked by:** 10 — 单笔 LLM 完整上下文分析。

**Status:** ready-for-agent

- [ ] 当前筛选范围可以主动发起批量分析，使用全范围而非当前列表页；超过 100 笔时提示缩小范围，不静默取前 100 笔，也不限制用户发起分析的次数。
- [ ] 批量表现结论仅采用对应数据完整的已结束交易，提供有效样本、排除数量和原因；当前选择范围与有效分析范围分别清楚展示。
- [ ] 包含全部有效统计、逐笔相关成交与订单、费用、原方案和核验、标签、允许的笔记及带时点的行情，冻结本次范围和证据。
- [ ] 复用已有长任务、报告、取消、用量和恢复能力；全量分段后综合，逐段记录交易及时间覆盖，任何遗漏、失败或截断都不产生完整报告状态。
- [ ] 最终报告明确综合阶段引用分段结果，各结论关联具体交易或统计分组；小样本规律、缺少原计划的交易及操作动机保持相应证据边界。
- [ ] 后台归档、编辑标签或笔记及切换筛选不修改运行中范围；旧报告保留其范围和时点，重复查看不会重新调用模型。
- [ ] 模型推测的风格分类单独展示，经用户确认后才成为个人标签，不把推测直接写成交易事实。
- [ ] 用户主动选择继续、重试或重新生成，不自动重复收费；无固定次数限制，未知用量和可能已发生的上游费用如实表达。
- [ ] 验证跨分页范围、100 笔边界、多币种、缺项排除、全量覆盖、分段失败、取消、运行中数据变化与证据引用；模型使用受控响应，HTTP 和浏览器流程均可独立验收。
