# 03: 复杂交易周期归并

**What to build:** 使用者能以完整交易查看分批入场、加减仓、反手和双向持仓历史。多头和空头分别归并，订单与成交仍可展开追溯；数量、盈亏及费用可对账，缺少关键证据的片段保持不完整状态。

**Blocked by:** 02 — 单币种真实历史同步。

**Status:** ready-for-agent

- [ ] 按已确认的交易周期规则归并同一合约、同一持仓方向；未归零前的加减仓属于同一周期，归零后再开仓形成新周期。
- [ ] 单向反手拆为旧交易结束和新交易开始，平仓数量与已实现盈亏归旧交易，剩余开仓数量归新交易，详情保留同一原始成交的关联。
- [ ] 反手手续费按数量比例分配，分配尾差归新交易，确保分配总额等于原手续费；数量和金额不使用浮点近似。
- [ ] 全仓、逐仓历史都纳入；双向持仓的多头和空头分别归并，保证金模式及历史杠杆无法确认时显示未知。
- [ ] 持仓中、已结束和数据不完整记录均可查看；缺少可靠开仓起点或成交链时不伪装成完整周期，浮动盈亏与已确认净盈亏分开。
- [ ] 资金费仅在证据足以唯一归属时计入交易；双向资金费、非 USDT 费用等无法确认时保留分项和缺失原因，不将未知金额当零。
- [ ] 归并结果可追溯到原始来源记录与归并版本；重复同步或补充历史不重复计入盈亏，已归档证据与既有单向简单交易继续可读。
- [ ] 详情展示实际入场与退出类型、分批数量、时间和持仓时长；类型缺失为未知，混合订单类型准确表达。
- [ ] 用独立金额和数量预期验证分批开平仓、同一时间多条成交、反手费用守恒、双向周期、缺失起点及资金费歧义；通过公开入口与浏览器验证复杂交易详情。
