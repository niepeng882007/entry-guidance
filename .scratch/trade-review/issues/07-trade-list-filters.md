# 07: 交易列表与组合筛选

**What to build:** 使用者能清楚浏览交易记录，按日期、币种、方向、净赢亏、记录状态、入场类型、方案关联和风格标签组合筛选，并从结果进入完整详情。未知信息和未确认净盈亏始终可辨认，筛选结果可作为后续统计、分析与导出的同一范围。

**Blocked by:** 05 — 个人笔记与交易风格标签；06 — 原方案关联与执行偏差。

**Status:** implemented — 自动与模拟验收记录见下文，实体手机及真实账户未验收

- [x] 默认按最近开仓在前显示记录，日期默认按开仓时间，可切换平仓时间；筛选参数、日期边界和时区在页面与业务入口保持一致。
- [x] 支持日期、币种、多空、净赢亏、持仓或完整性状态、入场类型、是否关联方案和风格标签的组合筛选及清除筛选。
- [x] 每条优先显示币种、方向、状态、净盈亏、开平仓时间和持仓时长，完整详情保留订单、成交、费用、方案及笔记关联。
- [x] 不同入场订单类型显示混合，查不到显示未知；净盈亏待确认不归入盈利、亏损或持平，持仓中和不完整记录保持可访问。
- [x] 列表分批加载或分页时结果总数、稳定排序和筛选范围一致；页面只加载部分记录不改变后续全范围统计或分析口径。
- [x] 服务端校验筛选参数，真实与模拟及账户数据保持隔离；未授权请求不能查询归档。
- [x] 修改筛选、离开页面或取消请求后，迟到响应不覆盖新范围；首次加载、空结果、失败与旧数据状态清楚表达。
- [x] 手机可快速筛选和展开详情，保持单位、焦点与触控清晰，遵循既有前端规则。
- [x] 使用公开入口及生产构建浏览器验证多条件组合、日期字段切换、未知类型、待确认盈亏、分页、空结果、非法参数和迟到响应。

## 已确认实施口径

- 日历日期固定 Asia/Shanghai，起止日均包含，后端转换成 UTC 半开区间；开仓与平仓时间显示同一时区。
- 每页 20 条，开仓时间倒序、交易 ID 升序，未知开仓排末；总数及公共 `list(filters)` 表达完整匹配范围。
- 多标签 AND；只使用归属 current 的已保存笔记，停用标签可筛历史。
- 开仓与加仓一起判定入场类型；已知和未知并存显示混合。仅 linked 为确认关联，ambiguous/unlinked 同属无确认关联并分别标注。
- TDD 公开边界：登录后的 HTTP 列表/详情与生产构建浏览器交互。未新增依赖、交易写接口或模型调用。
