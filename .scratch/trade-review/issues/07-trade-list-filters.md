# 07: 交易列表与组合筛选

**What to build:** 使用者能清楚浏览交易记录，按日期、币种、方向、净赢亏、记录状态、入场类型、方案关联和风格标签组合筛选，并从结果进入完整详情。未知信息和未确认净盈亏始终可辨认，筛选结果可作为后续统计、分析与导出的同一范围。

**Blocked by:** 05 — 个人笔记与交易风格标签；06 — 原方案关联与执行偏差。

**Status:** ready-for-agent

- [ ] 默认按最近开仓在前显示记录，日期默认按开仓时间，可切换平仓时间；筛选参数、日期边界和时区在页面与业务入口保持一致。
- [ ] 支持日期、币种、多空、净赢亏、持仓或完整性状态、入场类型、是否关联方案和风格标签的组合筛选及清除筛选。
- [ ] 每条优先显示币种、方向、状态、净盈亏、开平仓时间和持仓时长，完整详情保留订单、成交、费用、方案及笔记关联。
- [ ] 不同入场订单类型显示混合，查不到显示未知；净盈亏待确认不归入盈利、亏损或持平，持仓中和不完整记录保持可访问。
- [ ] 列表分批加载或分页时结果总数、稳定排序和筛选范围一致；页面只加载部分记录不改变后续全范围统计或分析口径。
- [ ] 服务端校验筛选参数，真实与模拟及账户数据保持隔离；未授权请求不能查询归档。
- [ ] 修改筛选、离开页面或取消请求后，迟到响应不覆盖新范围；首次加载、空结果、失败与旧数据状态清楚表达。
- [ ] 手机可快速筛选和展开详情，保持单位、焦点与触控清晰，遵循既有前端规则。
- [ ] 使用公开入口及生产构建浏览器验证多条件组合、日期字段切换、未知类型、待确认盈亏、分页、空结果、非法参数和迟到响应。
