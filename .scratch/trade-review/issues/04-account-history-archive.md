# 04: 全账户历史与持续归档

**What to build:** 使用者能同步当前账户全部 USDT 永续历史，查看全账户读取范围、进度和缺口。服务运行期间每 5 分钟持续增量归档，页面关闭仍可同步，服务重启后补查，并提供立即同步操作。

**Blocked by:** 02 — 单币种真实历史同步。

**Status:** ready-for-agent

- [ ] 初次发现并分批读取最近 3 个月的历史交易合约，覆盖未经过本工具的交易及历史已交易合约，不能仅依赖当前可交易币种列表。
- [ ] 复用已完成的单币种同步与当前归并能力，列表展示可确认交易及缺口；尚未具备复杂归并能力时相关成交链明确为不完整，不宣称所有周期已确认。
- [ ] 服务运行期间每 5 分钟增量同步，提供立即同步；同一账户的重叠请求合并或协调执行，不堆积并发任务或重复记录。
- [ ] 浏览器关闭不停止归档；电脑或服务停止期间暂停，重启依据持久进度补查。超过上游可查期限的区间保留缺口，不承诺恢复不可查询历史。
- [ ] 分来源、合约和区间记录进度与完整性，失败或未读完分页不推进完成区间；未能发现或读取的合约范围明确披露。
- [ ] 权限、身份、限流和网络失败可识别；同账户换密钥延续账本，不同账户及真实或模拟模式隔离，身份无法确认时停止新增归档。
- [ ] 页面展示全账户总进度、合约进度、最后成功时间和缺失区间；后台同步不触发 LLM 调用，也不改变原开仓方案或止损核验状态。
- [ ] 与现有账户及核验读取协调外部请求，保留访问保护和凭据脱敏；归档只读，不修改交易所状态。
- [ ] 用受控时钟和替换响应验证多合约发现、已下架合约、关闭页面后同步、重启补查、并发触发、限流恢复及过期缺口，并验证浏览器进度展示。
