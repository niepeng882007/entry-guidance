# 09: 单笔行情与交易事件图

**What to build:** 使用者在单笔详情查看持仓期间及少量前后行情，切换 K 线周期，并通过开仓、加减仓、平仓和止损标记回看执行过程。价格来源、原计划与实际证据分别表达，走势可作为 LLM 分析的有时点依据的上下文。

**Blocked by:** 06 — 原方案关联与执行偏差。

**Status:** ready-for-agent

- [ ] 从后端固定白名单公共 GET 读取并保存所需历史 K 线，默认覆盖持仓期间及少量前后行情，支持切换周期，记录来源、周期、时间范围与完整性。
- [ ] 图表叠加实际开仓、加仓、减仓和平仓事件，标记使用真实成交价格和时间，可关联到订单与逐笔成交。
- [ ] 有关联方案时展示原计划止损线，有实际历史证据时单独展示实际止损设置；标记价与合约成交价来源清楚，按止损的触发依据解释。
- [ ] 开仓前、持仓中和出场后行情可区分，事后走势不被当成当时已知信息；没有相关价格路径时不编造止损触发或精确逐笔走势。
- [ ] 持仓中、缺少起点或缺少订单元数据的记录仍可显示已知事件与相应缺项，不虚构开平仓边界或计划线。
- [ ] 历史行情分页未完成、过期合约不可查、断网或来源失败时保持缺口和已知时间，切换周期后的迟到响应不覆盖当前图表。
- [ ] 行情与事件证据可按同一来源和时点提供给分析；当前屏幕缩放或绘图抽稀不能被误称为全部原始数据。
- [ ] 手机与桌面可读取事件、价格和单位，图表交互支持焦点和无动效偏好，遵循已有前端规则。
- [ ] 从公开入口用受控行情验证分页、价格来源差异、单层或双层计划、反手事件、缺失行情与周期切换，并通过浏览器验证标记和详情关联。
