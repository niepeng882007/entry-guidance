# 12: CSV 导出与完整备份恢复

**What to build:** 使用者能导出当前筛选范围交易 CSV，并手动下载包含原始证据、方案关联、个人记录与分析报告的完整账本备份。恢复时先查看新增、重复和冲突，默认补入缺失记录，保留当前笔记与备份旧版本，任何失败不破坏现有账本。

**Blocked by:** 10 — 单笔 LLM 完整上下文分析。

**Status:** in-progress

- [ ] CSV 使用当前筛选范围全部记录而非当前列表页，时间、金额、单位、记录状态和未知值与页面一致，不能用空白或零伪装未确认净盈亏。
- [ ] CSV 字段正确处理换行、分隔符、引号与可能被表格解释为公式的自由文字，导出结果可对账。
- [ ] 完整备份包含原始来源证据、交易与归并版本、方案和核验关联、笔记、标签、已完成报告及分段结果、同步状态，凭据和登录信息不在备份内。
- [ ] 恢复前校验格式、版本、账户身份及真实或模拟模式，预览新增、重复、冲突和拒绝项；跨账户备份不能混入当前账本。
- [ ] 默认仅补入缺失记录并按来源身份去重，笔记或标签冲突时保留当前版本，将备份版本作为可查看旧版本；已有记录的覆盖由用户明确选择。
- [ ] 校验和写入原子完成，非法备份、冲突处理失败或写入错误不会部分覆盖现有账本；恢复进度和结果清楚表达。
- [ ] 导入同步状态不凭空证明历史完整，不把备份中的未完成分析变成成功，也不因恢复自动发起模型调用。
- [ ] 导出、下载、预览和恢复入口受登录、Origin 与账户隔离保护，数据仅作为结构化内容处理，不能修改后端配置或执行脚本。
- [ ] 模拟账本验证完整备份往返、CSV 对账、重复导入、缺失补入、笔记冲突旧版本、非法版本、跨账户拒绝和失败原子性；浏览器验证下载、预览、确认及结果，测试不操作用户真实账本。

## 已确认的实施范围

- JSON v1 完整结构化备份；当前筛选全范围 CSV。
- 仅同身份笔记/标签允许逐条选择覆盖，双方旧版本保留；其他冲突保留当前版本。
- 同名不同身份标签及关联不明的笔记保留备份旧版本。任何拒绝项阻止整份写入；确认时重新检查整个账本指纹。
- 测试边界为账本公开 API、HTTP 和 Playwright；所有测试使用模拟或临时账本。
- 初步定向测试已通过，完整检查和双轴审查待完成；实体手机、真实账户未验收。
